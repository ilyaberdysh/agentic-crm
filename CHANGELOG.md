# Changelog

Notable changes are collected here before a separately authorized release.

## Unreleased

### Added

- Agentic Core's first supervised vertical slice: note evidence, a proposed task diff, human approval, policy-brokered execution, an explainable queue, and a durable receipt.
- Provider-neutral inference contracts, encrypted provider-connection storage, an OpenAI-compatible adapter, and a bounded Codex CLI experiment.
- A record-level Agent tab and deterministic local demo.
- Repository overview, contribution guidance, security policy, and verified product screenshots.
- Apache-2.0 licensing, community health files, pull-request CI, and automated dependency update configuration.
- Workspace-scoped model connections for cloud and local providers, explicit unknown-cost accounting, runner dispatch, and scoped secret resolution.
- Enrolled runners with short-lived grants, authenticated MCP task creation, and an isolated Codex container sandbox.
- Recovery controls for stuck actions and blocked tasks, including an explicit cancelled queue outcome.
- Workspace module controls, full approval evidence and assignee details, and a read-only self-hosting doctor command.
- A documented source-provenance gate and follow-up backlog for the standalone runner and live Linux isolation certification.
- A product-owned public API contract with exact runtime-route parity, deterministic OpenAPI 3.1 generation, and drift checks.
- Canonical Agentic CRM storage and webhook identifiers, with migrations and compatibility aliases for existing integrations.

### Changed

- Replaced the historical generated API snapshot with schemas maintained from Agentic CRM's implemented routes.
- Removed stale product-research references from source comments and recorded the maintainer's source-use disposition for public OSS preparation.
